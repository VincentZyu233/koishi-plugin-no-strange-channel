# koishi-plugin-no-strange-channel

基于 Satori 协议的标准全平台**防乱拉群、自动拒绝陌生群邀请与自动退群**防风控安全卫士插件。

---

## 💡 诞生背景与典型场景

在使用野生个人 QQ 号通过 OneBot 协议端（如 **LLBot (LLOneBot)**、**NapCat**、**Lagrange** 等）接入聊天机器人时，经常会遇到以下困扰：
- **无节制拉群**：好友或陌生群友经常私自将 Bot 拉入各种非预期的陌生群聊。
- **腾讯官方高频风控**：Bot 加入的群聊数量过多、或群内人员发言敏感，极易被腾讯判定异常行为，导致账号遭遇警告、暂时冻结甚至永久封禁。
- **QQ 客户端无法关闭被动拉群**：QQ 原生设置无法完全禁止好友被动拉群进入讨论组或普通群。

**`no-strange-channel`** 由此而生：为 Bot 构建一道坚实的护城河，让 Bot 仅存在于您明确授权的白名单群聊中！

---

## ✨ 核心特性

- **🛡️ 三重主动防御纵深**：
  - **第一道防线 · 事前拒绝入群邀请**：收到入群邀请事件时（`guild-request`），非白名单群一律**自动拒绝**。
  - **第二道防线 · 事中瞬时拉入拦截**：当好友绕过邀请直接将 Bot 强制拉入新群时（`guild-added`），若不在白名单内，**立即主动退出**该群。
  - **第三道防线 · 事后发言巡检保底**：针对在插件开启前已被拉入的残留陌生群，一旦产生群发言（`message`），插件**防抖自动退出**。
- **🌐 原生全协议兼容**：
  - 基于 Satori 标准事件驱动，代码内部不做硬编码平台锁定；
  - 自动适配 OneBot `set_group_leave` 与标准 `leaveGuild`，优先无缝兼容 OneBot、Discord、KOOK 等平台。
- **👑 实时安全审计私聊**：
  - 发生拒绝入群或自动退群动作时，支持将详细审计报告（时间、目标群号、操作者、处置结果）私聊推送至主人账号。
- **⏱️ 智能群级防抖冷却**：
  - 内置防抖冷却队列，避免群内多人短时间内连续发言导致并发频繁向协议端发送退群指令。

## ⚙️ 配置说明

在 Koishi 控制台中进入插件配置：

1. **🛡️ 核心开关与白名单**：
   - `enabled`: 是否开启防护；
   - `whitelist`: 授权群聊/频道 ID 列表（在 OneBot 中即为纯数字 QQ 群号，如 `1085190201`）。
2. **🚫 陌生群邀请防御**：
   - `autoRejectInvite`: 收到非白名单群邀请时自动拒绝；
   - `rejectReason`: 拒绝申请时的理由说明。
3. **🚪 陌生群退出防御**：
   - `autoLeaveGroup`: 处于非白名单群时自动退群；
   - `sendNoticeBeforeLeave`: 退群前是否在群内发一条提醒（建议默认保持关闭，野生 Bot 静默退群最安全，避免被恶意群友举报）；
   - `leaveNotice`: 退群提醒文案；
   - `leaveCooldown`: 退群防抖冷却时长（默认 30 秒）。
4. **👑 主人通知与安全审计**：
   - `notifyMaster`: 是否向主人私聊推送拦截日志；
   - `masterAccounts`: 接收审计报告的主人平台与账号列表。

## 💡 平台与实例过滤建议

本插件不限制平台类型。若您只想让特定 Bot（如小号野生 QQ Bot）启用该功能，可在 Koishi 控制台插件配置顶部的**过滤器 ($filter)** 中自由勾选指定的 Bot 实例或特定平台（如 `onebot`），灵活性极高。
